# Dystopian Hobbies

Tienda online de coleccionismo otaku especializada en manga importado, cajas selladas de cartas coleccionables (TCG) y figuras de edición limitada.

## 🚀 Características
- **Catálogo interactivo** con más de 30 referencias organizadas por categorías (Manga, Cartas, Figuras).
- **Carrito de compras dinámico** desplegable con control de unidades y cálculo de totales en tiempo real.
- **Checkout simulado** con formulario de pedido y generación de referencia de envío.
- **Diseño Cyberpunk / Dark UI** responsivo para ordenadores y móviles con efectos CSS modernos y paleta neón.

## 📦 Despliegue
Este proyecto está preparado para desplegarse instantáneamente en **Vercel** como un sitio estático.
